# 变更记录

## 2026-10-12 安全修复

- 停用 `/auth/verify-birthday` 和 `/auth/reset-password`，均返回 410。生日是公开资料，无法证明账户归属；现有接口允许仅凭用户名重置密码。找回密码页面说明需联系管理员核实身份。保留验证原密码的修改密码功能；未来恢复自助找回时必须先实现可信的身份验证渠道。
- 用户资料修改仅接受邮箱和生日，拒绝余额、头像 URL 等受保护字段。头像通过上传接口更新。
- JWT 必须使用配置的随机密钥，校验必需声明、令牌用途和过期时间，并绑定当前密码版本。改密后已有登录令牌失效，前端要求重新登录。
- 注册、改密限制密码为 8–72 个 UTF-8 字节，避免 bcrypt 静默截断。CORS 只接受配置的来源。
- 头像限制请求体、文件大小和像素数量，实际解码 PNG/JPEG/WebP 后重新编码成 PNG，移除脚本和附加内容；忽略上传文件名和自报 MIME。存储错误不返回内部异常信息。
- 从已停止维护的 CRA 迁移到 Vite，组件扩展名改为 `.jsx`，入口 HTML 位于 `frontend/index.html`；升级 ECharts 和 React Router，提交前端锁文件。API 默认使用同源 `/api/v1`，开发代理目标可配置。
- 升级后端依赖到支持 Python 3.11、Pydantic 2 的版本；使用 PyJWT 和 bcrypt，移除有未修复告警的 python-jose/ecdsa 及未使用的依赖。更新 Docker Python/Node 基础版本，数据库和存储管理端口仅绑定回环地址。

验证：29 项后端安全回归测试；前端生产构建；通过前端代理访问的注册、登录、MySQL 联系人/文章增删改查与搜索、作者统计、MinIO 头像上传和匿名读取、改密后会话失效。测试使用临时 SQLite，集成测试记录和对象已清理。

依赖审计：迁移前 npm 报告 102 项告警，修复后 npm audit 为 0；修复后的 Python 环境 pip-audit 无已知漏洞。结果对应当前扫描数据库，未包含容器操作系统、MinIO 源码或第三方部署的完整审计。
